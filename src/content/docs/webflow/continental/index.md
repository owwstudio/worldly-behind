Dokumentasi project **Continental** yang menghubungkan desain Figma, implementasi
Webflow, dan custom code untuk motion serta interaksi.

**Hasil website:** [Lihat website Continental](https://continentals.webflow.io/).

**Desain:** [File Figma Continental](https://www.figma.com/design/FkXglC7ztx7bIPEcHOGSHD/MCP-by-irpun-dev-team).

## Urutan baca

1. [Perjalanan Proyek dan Keputusan](/webflow/continental/01-perjalanan-proyek/)
   — discovery, fondasi, eksplorasi, dan keputusan implementasi final.
2. [Struktur Halaman dan Design System](/webflow/continental/02-struktur-dan-design-system/)
   — hierarchy, komponen, token visual, layout, dan breakpoint.
3. [Motion dan Arsitektur Interaksi](/webflow/continental/03-motion-dan-interaksi/)
   — preloader, GSAP, ScrollTrigger, Lenis, model 3D, dan reduced motion.
4. [Aset, Operasional, dan QA](/webflow/continental/04-aset-operasional-qa/)
   — manifest aset, perawatan di Webflow, checklist QA, dan pemeriksaan konten.
