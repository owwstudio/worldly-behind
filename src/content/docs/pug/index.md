Dokumentasi Pug, templates, includes, mixins, dan workflow implementasi desain.

## Dokumentasi Verity

Dokumen berikut berasal dari project **Verity**, yang menggunakan MCP Figma
dan Pug. Stack dan aturan di dalamnya berlaku untuk project Pug yang
didokumentasikan.

**Hasil website:** [Lihat website Verity](https://enterprise-protoype-site.vercel.app/).

- [Verity: Project Playbook](/pug/verity/project-playbook/) — fondasi project,
  struktur folder, SCSS, GSAP, Lenis, responsive, asset, dan verifikasi.
- [Verity: Prompt Templates](/pug/verity/prompt-templates/) — 12 prompt yang
  dapat disalin untuk kickoff, implementasi section, revisi, QA, dan handoff.
- [Verity: AGENTS.md Template](/pug/verity/agents-template/) — template aturan
  pengembangan untuk digunakan pada project Pug baru.

## Dokumentasi MAKA Studio

- [MAKA Studio](/pug/maka-studio/) — ringkasan project, perjalanan implementasi,
  katalog prompt, keputusan, motion, validasi, dan handoff.

Dokumentasi ini dikelompokkan di kategori Pug sesuai struktur tim. Stack yang
tercatat di sumber MAKA Studio adalah HTML, CSS BEM, vanilla JavaScript, dan Vite.

## Dokumentasi Papersky

- [Papersky](/pug/papersky/) — marketing landing, dashboard marketplace demo,
  prompt, keputusan, implementasi, serta deployment dan handoff.

**Hasil website:** [Lihat Papersky](https://papersky.owwteam.dev) dan
[demo dashboard](https://papersky.owwteam.dev/app/overview).

Papersky dikelompokkan di kategori Pug sesuai struktur tim. Stack yang tercatat
di sumber adalah React, TypeScript, SCSS BEM, dan Vite; data dashboard bersifat fiktif.

## Dokumentasi Kindsight

- [Kindsight](/pug/kindsight/) — website fundraising, portal organisasi, admin,
  prompt, keputusan, implementasi, serta deployment dan handoff.

**Hasil website:** [Lihat Kindsight](https://kindsight.owwteam.dev/).

Kindsight berawal dari Pug dan vanilla JavaScript, kemudian bermigrasi ke React,
Vite, dan TypeScript dengan backend Express dan MySQL. Jalur Pug legacy tetap
menjadi referensi dalam dokumentasi.
